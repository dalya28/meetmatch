# MeetMatch · Живой зал и мобильная форма

## Для участника

После отправки анкеты MeetMatch показывает пять рекомендаций. На телефоне фокус переходит к заголовку «С кем познакомиться». При оценке карточки и смене языка страница сохраняет обычное поведение прокрутки. Если подбор завершился ошибкой, его можно повторить с заполненной анкетой.

Кнопка «Добавить меня в зал» под карточками публикует анкету для других участников. В зал попадает версия анкеты на момент нажатия. В этой же сессии можно менять поля и пересчитывать подбор. Участник видит подтверждение, а его собственная карточка исключена из результатов. Новая вкладка или перезагрузка может создать новую сессию Streamlit.

## Для организатора

Дашборд показывает число участников, которые сами добавили анкету. Для очистки задайте переменную окружения `MEETMATCH_ORGANIZER_CODE` перед запуском приложения. Когда в зале есть участники, откройте «Очистить живой зал», введите код и подтвердите действие. Данные анкет удаляются из хранилища и индекса рекомендаций. Отзывы и исходные 276 синтетических анкет сохраняются. После очистки участники могут присоединиться заново.

## Что проверено

| Проверка | Результат |
|---|---|
| Chrome, окно 375 × 812 | Пять карточек. Фокус на заголовке результатов, его верхний край на высоте 80 px. |
| Chrome, окно 1280 × 900 | Пять карточек рядом с формой. Страница поместилась по ширине на обоих экранах. |
| Автоматический ввод «Python Django» в готовую форму и отправка | 0,30 с на мобильной ширине и 0,22 с на настольной. Это измерение браузера без времени на обдумывание и ручной набор. |
| Регрессия Streamlit | Добавление, повторная отправка, верный и неверный код, очистка, повторный вход, повтор после ошибки. Пустые результаты и статус участника проверены на русском, казахском и английском. |
| Оценка рекомендаций | 21 размеченная анкета, P@5 = 0,98, nDCG@5 = 0,942. Для каждой анкеты подошли минимум три человека из пяти. |

Для командной проверки откройте MeetMatch на телефоне, заполните собственную анкету и засеките путь до первой подходящей карточки. На казахском проверьте, понятно ли из подписи кнопки, когда анкету увидят другие участники.

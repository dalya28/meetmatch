# Живой питч · целевой хронометраж 5 минут

| Время | Что сказать и показать |
|---|---|
| 0:00–0:35 | «Вы на митапе, у вас один кофе-брейк. Как найти человека, которому тоже нужен этот разговор?» Покажите первый слайд. |
| 0:35–1:10 | Объясните на примере Python-разработчика, зачем сначала проверять взаимность целей. |
| 1:10–2:40 | Нажмите «Соискатель». Прочитайте объяснение одной карточки. Откройте «Рекрутер», затем «Студент». Покажите первую фразу и общий слот. |
| 2:40–3:30 | Перейдите к слайду качества. На 21 размеченной анкете подошли в среднем 4,9 человека из пяти. Без взаимности целей — около 2,3. |
| 3:30–4:20 | Откройте дашборд. Покажите дисбаланс целей и объясните, кого стоит пригласить на следующий митап. |
| 4:20–5:00 | Назовите команду и предложите пилот. На реальном событии главный показатель — доля рекомендаций, которые привели к знакомству. |

**Если пропал интернет.** Запустите локальный Streamlit или откройте 30-секундный ролик из папки demo.

**Откуда данные?** Детерминированный генератор, 276 синтетических анкет. Живые участники попадают в зал по кнопке.

**Что именно проверено?** 319 размеченных пар. Результат относится к этому набору. Для оценки пилота нужны отзывы реальных участников.

**Зачем Claude?** Дополнительный режим уточняет подбор и текст. Базовые результаты доступны сразу. Метрики презентации относятся к базовой модели.

**Перед сдачей.** Дважды проведите выступление с секундомером, каждый раз до шести минут. Откройте публичный репозиторий, CSV, видео и PDF из чистого браузера. Срок по брифу — 21 ноября до 09:00.
